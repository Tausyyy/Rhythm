# Backend — ориентир по существующей структуре

Текущие проекты не переименовываются и не перестраиваются:
- `Ritm.Api` — контроллеры и HTTP-конфигурация.
- `Ritm.Services` — прикладные сервисы, DTO и маппинг.
- `Ritm.Data` — EF Core-контекст, сущности, миграции и seed-данные.
- `Ritm.Tests` — тесты.

Это описание текущего разделения ответственности, а не требование срочно создавать новые слои. Перед добавлением функциональности изучаем соответствующие существующие классы и расширяем их без дублирования.
